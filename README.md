# SA-MP Setup & Voice Plugin

Repositori ini menyediakan file installer Client SA-MP (San Andreas Multiplayer) beserta Plugin Voice yang sudah teruji **kompatibel** dan siap digunakan. Anda hanya perlu mengunduh file yang ada di repositori ini dan mengikuti petunjuk pemasangan di bawah.

---

## 🚀 Fitur Utama

- **Client SA-MP 0.3.7 R1 Installer**: Kompatibel dengan berbagai server SA-MP lokal maupun internasional.
- **Voice Plugin**: Kompatibel untuk komunikasi suara in-game tanpa kendala konektivitas.
- **Pemasangan Mudah**: Cukup unduh, pasang, dan langsung main.

---

## 🛠️ Panduan Cara Pemasangan (Installation Guide)

Ikuti langkah-langkah di bawah ini secara urut untuk memastikan game dan plugin berjalan dengan lancar:

### 1. Persiapan GTA San Andreas (Clean / Original)
- Pastikan Anda sudah memiliki folder **GTA San Andreas Clean / Original** (tanpa modifikasi berat yang merusak file dasar).
- Jika belum punya, Anda dapat mengunduhnya melalui situs penyedia mod/game terpercaya seperti [GTAInd](https://www.gtaind.com).
- **Saran Direktori:** Simpan folder GTA Clean Anda di direktori yang mudah diakses, contohnya:  
  `C:\Games\GTA San Andreas` atau `C:\GTA San Andreas`

---

### 2. Install Client SA-MP 0.3.7
1. Unduh file installer SA-MP yang ada di repositori ini:  
   👉 `2.sa-mp-0.3.7-R1-install.exe`
2. Jalankan (Double Click) file installer tersebut.
3. Saat proses instalasi meminta lokasi direktori, **arahkan/browse ke folder GTA Clean** yang sudah Anda siapkan pada Langkah 1.
4. Klik **Install** hingga selesai.

---

### 3. Pasang Plugin Voice
1. Masuk ke folder **Plugin Voice R1 R2** yang ada di repositori ini.
2. Unduh/ekstrak seluruh isi file yang ada di dalam folder plugin tersebut.
3. **Salin (Copy)** semua file hasil ekstrak.
4. **Tempel (Paste)** seluruh file tersebut langsung ke dalam **direktori utama GTA San Andreas** (folder yang sama tempat Anda menginstal SA-MP tadi). Jika ada peringatan *replace/overwrite*, pilih **Yes / Replace**.

---

### 4. Selesai! 🎉
Proses instalasi selesai. Anda bisa langsung membuka `samp.exe` di direktori GTA Anda, masukkan IP Server tujuan, dan nikmati fitur Voice Chat di dalam permainan!

---

## 📌 Catatan Tambahan
- Pastikan mic/microphone Anda sudah terdeteksi di Windows sebelum menjalankan permainan.
- Jika mengalami kendala *crash*, pastikan file GTA base Anda benar-benar *clean* sebelum diinstal SA-MP dan Voice Plugin.
